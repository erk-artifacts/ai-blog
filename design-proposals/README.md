# ブログデザイン刷新 — 調査とデザイン案（2026-08-15）

現行の「魔法の図書館 / Mystic Codex」テーマ（夜空 #0B1437 × 金 #FDC800 × 羊皮紙 #FFE9CE）からの大規模リニューアルに向けた調査結果とデモ。**まだ実装は開始していない。**

## 調査の要点

6つの角度（アワード受賞サイト / デザイン先進テック企業ブログ / 著名個人ブログ / 日本のWebメディア / 海外ニュースメディア / 2025-26トレンド）から並行調査した結論：

1. **テキストファーストが最上位の潮流** — Anthropic Newsroom・Vercel Blog・Stratechery 等、一流サイトほど「日付＋タイトル＋一行要約」のサムネイル無しリストで記事を提示。毎日1本・画像なしの本ブログと相性が良い。
2. **高級感＝引き算** — 余白、1pxヘアライン罫線、アクセント1色、タイポグラフィ階層のみで構成。装飾（グラデ・シャドウ・テーマ演出）は排する。
3. **日本語組版の定石** — 本文16-18px・行間1.8-2.0 / 見出しに `font-feature-settings: "palt"` / 純黒×純白のペアは避ける / 日付・ラベルは英字モノスペース（IBM Plex Mono続投可）/ 見出しは `word-break: auto-phrase`。
4. **ダークで細字は禁物** — ダーク地の日本語本文は Noto Sans JP 500 以上（Raycast の body-500 ルール）。
