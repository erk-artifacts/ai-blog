## Anthropic's Claude Code Exposes Source Code Due to Misplaced Source Maps

A security incident occurred with Anthropic's AI development support tool "Claude Code," making source code temporarily accessible. The cause was the accidental inclusion of source map files in an npm package (JavaScript external library distribution service).

Anthropic described the incident as "human error, not a security breach," and denied any customer data leakage. However, analysis and re-implementation efforts of the leaked code are spreading, drawing attention to AI companies' security management practices. Multiple incidents occurred at the company within the same month, making operational improvement a critical issue.

[→ Read the original article (ITmedia AI+)](https://www.itmedia.co.jp/news/articles/2604/01/news056.html)

**Impact on Daily Life:** Strengthened security practices at AI companies will improve the reliability and safety of AI services used by consumers.

## Ollama Implements Mac MLX Support, Accelerating Local Model Execution on Apple Silicon Macs

Ollama (a tool for running AI models in local environments) added support for Apple's MLX (machine learning optimization framework). This significantly improves performance when running AI models on Apple Silicon MacBooks (M1 and later).

By more efficiently utilizing Mac's unified memory (memory shared by CPU and GPU), high-speed inference is possible while reducing power consumption. Powerful AI models can now run on personal Macs in private environments, reducing dependence on cloud services.

[→ Read the original article (Ars Technica AI)](https://arstechnica.com/apple/2026/03/running-local-models-on-macs-gets-faster-with-ollamas-mlx-support/)

**Impact on Daily Life:** Mac users can leverage advanced AI models privately on their own computers, achieving both privacy protection and improved processing speed.

## Summary

As of April 1, 2026, the AI industry is reaching multiple important milestones. OpenAI's $122 billion fundraising symbolizes the full-scale acceleration of AI technology investment. Conversely, security incidents at Anthropic and Mercor suggest that addressing security and ethical issues is urgent as AI develops rapidly.

Through Salesforce's AI integration into Slack and the implementation of business automation AI (estie, TOKIUM) across companies, AI technology is definitely transitioning to the practical implementation stage. Furthermore, tools like Ollama are advancing AI democratization, enabling advanced AI models to operate in personal environments.

These trends suggest that three directions will advance simultaneously going forward: AI trustworthiness and security, industry-specific practical applications, and local environment operations.
