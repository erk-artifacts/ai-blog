## ChatGPT Adds New Security Feature: "Lockdown Mode"
OpenAI has begun offering a new security feature, "Lockdown Mode," for ChatGPT. This aims to reduce the risk of data leakage from prompt injection attacks (attacks that use malicious commands to extract sensitive information from AI). When enabled, it restricts web browsing and connections to external services.
[→ Read the original article (ITmedia AI+)](https://www.itmedia.co.jp/news/articles/2606/07/news022.html)
Enhanced AI security will allow businesses and individuals to handle sensitive information with greater peace of mind.
